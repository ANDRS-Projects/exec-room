# Contributor License Agreement: signatures

Each line under "Signatures" is one contributor's signature under the
[Contributor License Agreement](CLA.md).

This file is public. What is recorded and why: see the privacy note in CONTRIBUTING.md.

To sign, add one line at the end of this file, in your own pull request, with your GitHub username
and today's date, exactly in this form:

    - @your-username, YYYY-MM-DD: I have read the Contributor License Agreement (version 1) and I agree to it.

Add only your own line, and don't change or remove any other line. The **CLA** check on your pull
request reads this file. See [CONTRIBUTING.md](CONTRIBUTING.md#license-and-contributor-agreement).
